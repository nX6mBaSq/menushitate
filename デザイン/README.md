# ホームページ デザイン（v1.0）

作成日：2026-11-16
元資料：サイトマップ v1.0／ワイヤーフレーム v1.0

---

## 1. 見方

`index.html` をブラウザで開くと、全32ページの一覧とスタイルガイドが表示されます（サーバー不要。ダブルクリックで開けます）。

各ページの左下にある確認用パネルで、次の表示を切り替えられます。設定はページを移っても保持されます。

| 操作 | 内容 |
| :-- | :-- |
| 表示 PC / SP | PC幅とスマホ幅（390px）の切り替え。SPではハンバーガーメニューと画面下の固定CTAバーが表示されます |
| フェーズ 1 / 2 / 3 | 公開フェーズごとの表示（Phase 1はナビの「導入事例」の代わりに「モニター募集」を表示） |
| 設計メモ ON / OFF | ワイヤーフレームの注釈とセクション番号の表示（初期状態はOFF） |

URLの末尾に `?view=sp&phase=2&notes=on` を付けても切り替えられます。

## 3. デザインの方針

**コンセプト：「メニュー表のように、静かに、確かに売れる」**

「見た目の良いメニューを作る会社」ではなく、「利益を設計する会社」と伝わることを優先しました。

| 要素 | 内容 |
| :-- | :-- |
| 配色 | 生成り `#f7f2e9`（ベース）／墨 `#1f1c17`（文字）／朱 `#c8402a`（**CV専用**）／深緑 `#22302a`（ダーク面）／金茶 `#b8892e`（数字・英字） |
| 見出し | Shippori Mincho B1。上質なメニュー表の雰囲気を出す |
| 本文 | Zen Kaku Gothic New。読みやすさを優先 |
| 数字・英字 | Fraunces。客単価や価格などの数字を目立たせる |
| CV | 朱色は「無料相談」「モニター募集」だけに使う。「資料DL」は枠線ボタン |
| 図版 | 4象限図・メニュー表・スマホ画面・推移グラフ・販促カレンダーなどは `site.js` でSVGとして自動生成 |
| 写真枠 | 料理写真は100%実写の方針に合わせ、写真の入る場所は暖色のグラデーション＋カメラのラベルで示す（AI画像は使わない） |

## 4. 仮置きしているもの

- **ロゴ・社名**：「Menu Logic（仮）」とロゴマークを仮に置いています。正式な社名・ロゴが決まったら `assets/site.js` の `logo()` を差し替えてください
- **写真**：写真枠はすべて仮です。撮影後、`.ph` の要素を `<img>` に置き換えてください
- **数値・文言**：「○」などの未確定事項は、ワイヤーフレームの README「要決定事項」と同じです
- **フォーム**：見た目だけです（選択肢はクリックで選べますが、送信はしません）
