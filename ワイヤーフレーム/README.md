## 1. 見方

`index.html` をブラウザで開くと、全32ページの一覧から各ワイヤーフレームへ移動できます（サーバー不要、ダブルクリックで開けます）。

各ページ上部の黒いバーで、次の切り替えができます。設定はページをまたいで保持されます。

| 操作 | 内容 |
| :-- | :-- |
| 表示 PC / SP | PC幅（最大1280px）とスマホ幅（390px）を切り替え。SPではハンバーガーメニューと画面下の固定CTAバーが出ます |
| 注釈 ON / OFF | 黄色の設計メモ・セクション番号・ページ情報の表示を切り替え |
| 公開フェーズ 1 / 2 / 3 | そのフェーズで公開するナビ・セクションだけを表示（例：Phase 1は「導入事例」の代わりに「モニター募集」） |

表記ルール

- グレーの「×」の箱：画像・図のプレースホルダー
- **赤**：CV（コンバージョン）要素。メインは「無料相談」（赤ボタン）、サブは「資料DL」（枠線ボタン）
- 黄色の枠：設計メモ（注釈）
- 文言はすべて仮。「○」は未確定の数値・名称

## 3. 共通パーツ

| パーツ | 内容 |
| :-- | :-- |
| ヘッダー | ロゴ／メソッド／サービス▼（4サービス）／料金／導入事例（Phase 2〜）またはモニター募集（Phase 1）／コラム（Phase 2〜）／[資料DL]／[無料相談する] |
| 共通CTA | 各ページ末尾。「無料相談」＋「資料DL」。Phase 1のみモニター募集への導線を追加。フォーム系・パートナー向けページでは非表示 |
| フッター | サイトマップ「4. ナビゲーション設計」のとおり4列。公開前のページはフェーズに応じて非表示 |
| SP固定バー | スマホ表示時、画面下に「資料DL／無料相談」を常に表示 |

## 4. 設計上のポイント

1. **景品表示法への配慮をサイト自体でも徹底**
   Phase 1は実績がないため、「客単価+10〜15%」は「設計目標」と表記。料金ページの投資対効果は「試算」「保証しない」を明記。事例の数値は測定期間とセットで掲載する。
2. **価格を早めに見せる**
   トップのSEC-06で価格帯を提示し、根拠は料金ページ（ROI試算・権利料金）で説明。格安代行との価格比較にならないよう、「私たちについて」でタイプ別の比較表を置く。
3. **フェーズで出し分け**
   Phase 1は空のページを見せない。導入事例・コラム・パートナー募集は Phase 2 から、デザイナー募集は Phase 3 から表示。
4. **A（経営者）とB（パートナー）の導線を分ける**
   問い合わせフォームを分け、パートナー募集ページだけはB to B向けの言葉づかいと専用CTAにする。
